# Promotions and Discount Codes

## Using a discount code

Enter the discount code at checkout before payment. Only one code can be used per order, and codes cannot be applied to gift cards.

## Seasonal sale terms

Seasonal sale prices are valid while stock lasts. Items bought on sale can be returned within the normal 30-day return window and are refunded at the price paid. ## Expired codes

Expired codes cannot be reactivated. Price adjustments are not available for purchases made before a sale started.
